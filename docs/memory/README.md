# 项目记忆

为任何在 Augur 上工作的人（尤其是 LLM）保存的、跨会话的持久上下文。
这是**项目级记忆**——区别于 Codex/Claude 等工具自己的个人记忆。

## 什么该放这

那些未来会话会重复浪费时间去重新发现、又不适合放进代码、`AGENTS.md` 或 ADR 的东西：

- **数据源怪癖** —— 如"akshare 某端点 16:00（CST）后不稳"、各市场符号格式的坑、踩出来的限流阈值。
- **主人偏好** —— 工作流、默认项、主人提过一次但应长期生效的要求。
- **死胡同** —— "我们试过 X，因为 Y 没成；无新信息别重试。"
- **非显然的接线** —— 出人意料的耦合、某 workaround 为何存在。

## 什么不该放这

- 带权衡的架构/决策 → 写 **ADR** 到 `../decisions/`。
- 当前状态 / 下一步 → **`../roadmap.md`**。
- 不变量与约定 → **`../../AGENTS.md`**。
- 任何读代码就能得到的东西。

## 约定

- **一文件一主题**，kebab-case 命名：`data-source-quirks.md`、`owner-preferences.md`。
- 每个文件开头一句话摘要。涉及时效的条目标注日期。
- 任务中途学到持久的东西，**在结束这一轮前就写到这里**。
- 变假了就删——过时的记忆比没有更糟。
