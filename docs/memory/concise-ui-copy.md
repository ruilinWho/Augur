# Concise UI Copy

作者偏好：功能摆在界面里即可，不要用解释性文案占据主界面。

- 空态只写对象状态：`暂无日报`、`暂无资讯`、`暂无标的`、`选择标的`。不要写“从左侧选择”“点某按钮开始”“让 LLM 帮你……”这类教学句。
- 加载 / 生成 / 清洗中的文案也保持短：`加载…`、`生成中…`、`聚类中…`、`识别中…`。复杂流程用状态点或进度结构表达，不用长句。
- 设置页默认是短标签 + 控件。只有涉及密钥、隐私、外部网络、成本、不可逆删除等风险时，才加说明。
- 主舞台工作面默认全宽，不加随手的 `max-width`。已踩过的坏味道包括：空态 `320px`、笔记编辑器 `920px`、旧设置容器 `640/1280px`。
- 如果 UI 支持拖拽栏宽，外观页应提供恢复默认布局，避免作者把工作台拖乱后需要清 localStorage。
