# ADR 0010 — 从研究辅助升级为决策级主动投资工作台

## 背景

作者明确调整目标：Augur 不应停留在“非投资建议 / 研究辅助”的弱表述，而应成为一个本地优先、LLM 驱动、足以支撑作者**仅通过 Augur** 做出上好、精良、专业、时效、全面、主动 / Active / 激进投资决策的工作台。

## 决策

- 产品目标改为 **decision-grade active investing workbench**：看、研、知、记都服务主动决策，而不是只陈列信息。
- 保留硬边界：Augur 永不下单、不动钱、不执行交易；作者仍是交易执行主体。
- 所有主动结论必须可追溯：来源、时间、新鲜度、触发条件、反证条件、关键不确定性必须显式存在。
- 「知」新增**决策**视图：把当日机会、风险/反证、催化、关联标的集中到一个工作台。
- 「资讯」第三层从固定“新闻/推特”扩为多信源 lane：新闻、推特、Reddit、雪球、小红书等都进入同一套时间线 / 要点 / 过滤 / 标股体系。

## 取舍

- 正面：目标更贴近作者真实用法；LLM 输出从“摘要”转向“动作判断 + 反证条件”；不同信源不再是孤岛。
- 风险：主动/激进口径更容易被模型写成确定性结论。用来源、反证、触发条件、不可执行交易边界来压住幻觉和过度自信。
- 小红书 / 雪球属于登录型或不稳定抓取源；先登记配置与 UI lane，不伪装已接入。Reddit 可用公开 JSON，先接入真实适配器。

## 后续

- 接入雪球 token/cookie 后，把雪球关键词流写入 `source='雪球·<keyword>'`。
- 小红书需要稳定登录 Cookie 或第三方 API 后再接，不使用脆弱匿名爬虫冒充数据源。
- 决策视图后续应加入仓位假设、触发价位、事件日历、分区级机会雷达，但仍不执行交易。
