# ADR 0003 — 标的检索数据源 · 判断日记 · 可调栏宽

- **状态：** 已接受
- **日期：** 2026-06-01
- **决策者：** 主人 + Claude

> M1.6 一批主人驱动的功能：把"加新股"做到好用（模糊检索全市场、拖拽换区）、给个股加"判断日记"复盘、左栏可拖拽调宽。

## 背景

M1 的加股要手输 `MARKET:CODE`，且没有名称检索；主人反馈港股 MiniMax/智谱 等新股根本搜不到。同时提出三项体验诉求：拖拽改分区、左栏可调宽、个股下方的"判断日记"复盘。

关键调研结论（2026-06 实测，详见 `docs/memory/search-data-sources.md`）：
- `FinanceDataReader.StockListing` 能出美/中/韩列表但**名字是英文/韩文**、**不支持港股**、且**很慢**（美股 ~70s）。
- **东方财富 suggest API**（`searchapi.eastmoney.com`）实时、最全、含拼音，港股/A股/新股全覆盖（MiniMax、智谱都有）——但**噪声重**（杠杆 ETF/牛熊证/票据）、**无韩股**、美股按名搜噪声大。
- akshare 港股列表走 `push2.eastmoney.com`，本机代理拦截 → 不可靠。

## 决策

**1. 检索 = 本地目录 ∪ 东财实时联想，统一打分去重（`market/search.py`）**
- 本地目录（`listings.py`，缓存 Parquet）：US/CN/KR 用 FDR；A股中文名用 akshare 合并；KR 列表用 `StockListing('KOSPI'/'KOSDAQ')`（带韩文名）。负责**美股英文名 + 韩股 + 离线兜底**。
- 东财 suggest：负责**港股/A股/新股 + 拼音**。按 `Classify` 映射 `HK/AStock/UsStock`→我方市场，过滤衍生品/票据噪声（港股 `购/沽` 仅限港股过滤，避开 A股「苏宁易购」误杀）。30min TTL 缓存 + 4s 超时 + 失败降级到本地。
- 跨语言别名种子 `resources/sources/aliases.yaml`（版本化）：海力士→KR:000660、英伟达→US:NVDA 等。这是"东财无韩股、FDR 韩股名是韩文"下，**海力士搜得到**的唯一可靠途径。
- 前端：检索式加股取代手输 `MARKET:CODE`——选了某市场只敲代码即可加入，`全部`则全市场搜；加完即选中并加载 K 线。

**2. 拖拽换区（dnd-kit）**
- 标的行可拖拽，板块标题为落点，跨板块移动 + 同区重排。后端新增 `PATCH /watchlist/items/{id}`（move）配合既有 `/reorder`。

**2b. 分区按"标的所在市场"显示（主人定，2026-06-01 追加）**
- 分区**可跨市场**（半导体 = NVDA 美 + 海力士 韩）。选具体市场时 `list_tree` 按内容剪枝：只露出在该市场有标的的分区、且只显示该市场的标的；空分区 / 在该市场无标的的分区**只在「全部」出现**。修主人反馈"`大模型` 不该出现在韩股"。
- 替代（否决）：**每个分区死绑一个市场**——更"死板"，且跨市场主题要在每个市场各建一个同名分区，对多市场研究台不友好。

**3. 判断日记（`journal/` 域 + K 线下方面板）**
- 新 SQLite 表 `journal_entries(symbol, entry_date, body, …)` + CRUD（`/journal/entries`）。
- 前端在「看」视图 K 线下方：按日期倒序的可折叠卡片，支持加/改/删/改日期，带"N 天前"相对标签强化复盘语境。
- 定位：这是 §1「研」支柱的**轻量前身**——人写的决策依据，日后回看是否正确；M2 的 LLM 深度分析将与之并存。

**4. 左栏可调宽**
- `--panel-w` CSS 变量 + 拖拽手柄（原生 pointer 事件，非 dnd-kit），夹在 `[208,520]`，持久化到 `augur-ui`。K 线用 Lightweight Charts `autoSize` 自适应回流。

## 考虑过的替代方案

- **只用本地缓存列表（不接东财）** —— 否决：港股没列表源、新股滞后、无中文/拼音检索，主人的 MiniMax/智谱诉求满足不了。
- **只用东财 suggest（弃本地）** —— 否决：东财无韩股、美股按名搜噪声大、断网即废；本地目录是离线兜底与美股/韩股的主力。
- **引 rapidfuzz / pypinyin 提升模糊度** —— 暂缓：东财自带拼音、本地手写打分够用；真正缺口是港股**数据覆盖**而非算法。需要时再加。
- **判断日记并入 M2「研」** —— 否决：复盘是高频轻量操作，主人要它"现在就能用"，独立小域更快落地，且与 LLM 研究正交。
- **栏宽用预设档（窄/中/宽）而非自由拖拽** —— 否决：主人明确要"拖拽变宽变窄"。

## 后果

**正面**
- 港股/A股/新股 + 中文/拼音/英文/韩文跨语言检索一把搞定；离线仍可用（降级本地）。
- 判断日记把"有复盘的决策"落了地，是「研」的自然前身。
- 栏宽自由、K 线自适应，主人可按屏与心情调布局。

**代价 / 风险**
- 依赖东财公开 suggest 端点（token 可能变、被限流）——已做缓存/超时/降级，且本地兜底；token 写在 `search.py` 常量，失效时改一处。
- 引入 akshare（重依赖树）用于 A 股中文名；CN 中文名失败会降级英文名，不致命。
- 东财噪声过滤是启发式（名称关键字），可能漏过个别衍生品或误杀极少数含「购/沽」港股；可按反馈迭代 `_EM_NOISE`。
