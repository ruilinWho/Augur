# 设计系统 — Augur

> Anthropic 对齐、暖色纸感、排版优先。[CLAUDE.md](../CLAUDE.md) §9 的配套文档。
> **本项目对前端美观度要求极高——把这份文档当成资深产品设计师的工作规范。**

## 0. 为什么美学对 Augur 是**功能性的**（不是装饰）

Augur 处理的是高波动、极易激发情绪的金融数据。**界面若嘈杂、刺眼、拥挤，会放大焦虑、诱发冲动，直接损害投资的理智性。** 反过来，一个平静、清晰、克制的界面，能降低认知噪音与情绪波动，让主人更清醒地思考、做更理性的决策。

所以 Augur 的 UI 目标**不是"好看"，而是"用平静与清晰把噪音降到最低"**。Anthropic 的暖色纸感美学之所以适配，正因为它天然冷静、以阅读为中心、不喧哗——这与"帮助主人冷静思考"的产品目的同构。

**四条第一性原则：**
1. **平静优先**（Calm over loud）—— 安静的界面胜过抢眼的界面。
2. **清晰优先**（Clarity over density）—— 一屏少而清，胜过多而乱。
3. **克制**（Restraint）—— 每个强调、每段动效都要有理由。
4. **阅读为中心**（Typography-first）—— 这是文本与图表为主的产品，字排得好，气质就成了。

## 1. 完成标准 · 任何一屏的验收清单（Definition of Done）

把这当成资深设计师的过稿清单。**做不到就继续打磨，绝不交付默认/未对齐/粗糙的界面。**

- [ ] **视觉层级**：一眼看出主次；最重要的元素最突出，其余安静退后。
- [ ] **对齐与节奏**：所有元素落在同一套间距网格上；必要处做**光学对齐**而非机械对齐。
- [ ] **留白**：宁可多留白——拥挤是默认的失败态。让内容呼吸。
- [ ] **排版**：行宽 45–75 字符；行距充足；价格/数字用 `tabular-nums` 对齐；标题衬线、正文无衬线分工清楚。
- [ ] **颜色**：强调色只在关键处点睛；大面积是中性纸感；明暗都暖。
- [ ] **波动数据冷静化**：不狂闪红绿、不把盈亏游戏化；涨跌色按市场习惯。
- [ ] **状态完整**：loading / empty / error / 流式中途 都设计过，不是事后补。
- [ ] **动效**：有意义、克制（120–240ms）、尊重 `prefers-reduced-motion`。
- [ ] **终检问句**：**"资深产品设计师会让它上线吗？"** 否则继续。

## 2. 颜色 token

以 CSS 变量定义；Tailwind 映射到它们。下列为参考值（实现时再微调）：

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#F5F4EE` 象牙 | `#1F1E1B` 暖炭 | 应用背景 |
| `--surface` | `#FBFAF6` | `#2A2825` | 卡片、面板 |
| `--border` | `#E6E3D8` | `#3A3733` | 发丝描边 |
| `--text` | `#1A1915` | `#ECEAE1` | 主文本 |
| `--text-muted` | `#6B675C` | `#A8A395` | 次文本 |
| `--accent` | `#D97757` 陶土/珊瑚 | `#E08A6A` | 唯一标志强调色 |
| `--accent-weak` | `#F0DDD2` | `#4A382F` | 强调背景 |
| `--up` | `#3F8F5B`（美股绿） | — | 涨（见下注） |
| `--down` | `#C24A3E`（美股红） | — | 跌 |

> **涨跌色市场习惯：** 美股/全球 绿涨红跌；A股/港股/韩股文化上**红涨绿跌**。把涨跌色做成**按市场（或用户）可配**，不是常量。

## 3. 排版

- **标题——衬线**（Tiempos/Copernicus 感）。免费近似：**Newsreader** 或 **Source Serif 4**。
- **正文 / UI——人文无衬线**（Styrene 感）。免费近似：**Inter**。
- **数字/数据——等宽数字**（`font-variant-numeric: tabular-nums`），价格列对齐。代码/JSON 用 **Geist Mono / JetBrains Mono**。
- Anthropic 真品牌字体（Styrene A/B、Tiempos）是**商业授权**——我们在 `resources/fonts/` 放免费替代，可换。

**可调排版——CSS 变量契约：**
```css
:root {
  --font-serif: "Newsreader", Georgia, serif;
  --font-sans:  "Inter", -apple-system, system-ui, sans-serif;
  --font-mono:  "Geist Mono", ui-monospace, monospace;
  --text-base:  16px;   /* 用户可调 */
  --leading:    1.6;    /* 行距，用户可调 */
  --measure:    68ch;   /* 阅读最大行宽 */
  --tracking:   0;      /* 字距 */
}
```
字号梯度（相对 `--text-base`）：`0.8 / 0.9 / 1 / 1.25 / 1.6 / 2.1 / 2.6`。设置面板暴露：基准字号、行距、字体族、行宽 → 写这些变量。

## 4. 间距、圆角、层级

- **间距梯度（px）：** `2 4 8 12 16 24 32 48 64`。优先用大间距——让它呼吸。
- **圆角：** `--radius-sm 6px`、`--radius 10px`、`--radius-lg 16px`。柔和，绝不尖锐。
- **层级：** 优先发丝描边 + 极淡阴影，少用厚重投影。浮层用一个柔和阴影 token。

## 5. 动效

- 用 **Motion**（motion.dev），**克制**。时长 `120–240ms`，缓动 `ease-out` / 柔和 spring。
- 只动透明度 + 小位移；避免弹跳/缩放的戏剧化。流式文字要平滑出现，不跳。
- 尊重 `prefers-reduced-motion`。

## 6. 图表

- Lightweight Charts v5 按 token 主题化：象牙背景、发丝网格、低调坐标文字、强调色十字光标。涨跌色遵循各市场习惯（§2）。多窗格放主图 + 指标。
- 图表 chrome 极简——**数据是主角**。

## 7. 组件准则

- 卡片/面板：`--surface` + `--border` + `--radius`，充足内边距。
- 按钮：主操作用 `--accent`；多数动作要安静（ghost/outline）。**每屏最多一个"响亮"按钮。**
- 输入框：平静、宽松、清晰的 `--accent` 聚焦环。
- 用 **Radix UI** 无头原子件保证无障碍与交互正确，再用我们的 token 上妆（不直接套用别人现成的视觉）。
- 永远对着 token 写——**组件里不出现字面颜色/尺寸**（CLAUDE.md §5）。

## 8. 参考坐标（touchstones）

平静、克制、高完成度的产品，研究它们怎么处理留白、层级、动效与数据密度：
**Claude.ai · Linear · Things 3 · Stripe 文档 · Arc**。

做 Augur 任何界面前，先想："如果这是上面某个团队出品的，它会长什么样？"
