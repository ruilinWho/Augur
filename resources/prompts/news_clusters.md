# 任务

1. **聚类去重**：把报道**同一事件 / 同一进展**的多条新闻合并成**一个簇**（哪怕措辞不同、来源不同、中英混杂）。每条新闻只归入一个簇。零散但独立的事件各自成簇。
2. 每个簇给出：
   - `headline`：一句**中文**合并标题——客观、信息密度高、点出主体与事件，不夸张、不喊单、不用感叹号。
   - `importance`：该簇对**投资研究**的重要性（4 级）：
     - `critical` = **非常重要**：可能显著改变行业格局或某公司基本面的重磅——颠覆性技术突破 / 超大额并购或融资 / 关键监管或地缘事件 / 远超预期的财报或指引 / 重大供需拐点。**从严，只给真正影响判断的少数。**
     - `high` = 重要：值得了解的明确进展——重要订单·产能 / 一般并购 / 政策动向 / 重要产品或合作 / 明确催化。
     - `med` = 一般：有信息量但非关键，或影响待观察。
     - `low` = 次要：重复炒作、边角八卦、纯盘面涨跌、泛泛展望、无具体驱动。
   - `why`：≤30 字，为何值得关注（或为何不重要）。
   - `members`：该簇包含的 `[n]` 序号数组（至少 1 个；只用上面真实出现过的序号）。
3. **整体按 importance 从高到低排序**输出（critical → high → med → low）。纯噪音、无价值的内容可以**直接丢弃、不输出**。
4. 只用所给条目里的事实，**不编造**；**不写投资建议、不给买卖结论**。

# 输出

只输出 JSON（不要解释、不要围栏）：

```
{"clusters":[{"headline":"…","importance":"critical|high|med|low","why":"…","members":[1,5,9]}]}
```
