我要你扮演一位严谨的供应链研究分析师，用「卡点 / 稀缺层」方法论，对 {MARKET}股票 **{NAME}（{STOCK}）** 做一次深入的、基于公开证据的研究。这是研究辅助，不是买卖建议——最终决策由我自己做。

请**联网查证**，强结论必须落到一手证据（公告、财报、电话会纪要、交易所文件、招投标、问询函/互动易、监管与项目审批、专利、标准、官方订单/合同）。社媒与大 V 帖子只能当线索，不能当证据。注明数据截止日期。

## 一、把故事拆成系统变化
- {NAME} 所在的终端需求由什么宏观/技术变化驱动？这个驱动是结构性的还是一阵风？
- 这个变化让哪个老设计变得吃紧？最关键的物理/经济约束是哪一个：算力、带宽、功耗、散热、良率、纯度、认证周期、产能、并网、监管？

## 二、把产业链摆开，定位 {NAME}
按这几层展开：终端需求 → 系统集成/整机 → 模组/子系统 → 芯片/器件 → 工艺/封测 → 设备/量测 → 材料/耗材 → 物理基础设施。
**明确指出 {NAME} 卡在哪一层**，以及它在那一层是「控制稀缺环节 / 供给稀缺环节 / 只是受益于主题 / 有敞口但无定价权 / 故事好但证据弱」中的哪一种。

## 三、稀缺层判定（{NAME} 真的难被绕开吗）
逐条回答，给证据：
- 供应商数量是否很少？客户认证/导入周期是否很长？扩产是否困难（资本、设备、know-how、材料纯度）？
- 客户是否表现出紧迫（预付款、锁产能、长协、加急、接受涨价）？有没有客户把竞品从供应商名单移除、或财报里出现 sole/primary source、design-in 字眼？
- 真正干活的是不是 {NAME} 本身（而非更大的母公司品牌）？价值是否其实在某个子公司/上游？

## 四、第一性原理五杠杆
逐条点名 {NAME} 的**最强项**与**最弱项**：①需求持久性 ②供给瓶颈（能持续多久）③定价权（能否提价/守毛利）④资本强度（扩产要多少 capex/稀释；别只看低 P/B，要看 ROIC、利用率、毛利）⑤法治/地缘（产权、补贴、管辖、供应链主权敞口）。

## 五、Buffett 质量闸门（**每项默认「未验证」，只有引用了财报/纪要/文件证据才能升级**）
- **护城河**：未验证 → 弱/中/强（一句话理由：认证壁垒/切换成本/IP/规模/牌照）。
- **赚钱能力**：未验证 → 改善中/已证明（只有引用了营收/毛利/现金流数字才算；指引和管线最多算「改善中」）。
- **客户替换风险**：未验证 → 低/中/高（认证周期、是否有二供、客户集中度）。
- **当前结论**：证据不足 / **研究地图** / 可投资结论（后者必须护城河+财务+估值+安全边际都到位——**绝不凭帖子或股价异动**）。默认落到「研究地图」。

## 六、叙事卫生（别把情绪/资金当基本面）
质疑阶梯被逐级证伪导致的 re-rate、媒体 FUD/meme 标签、指数纳入/逼空——这些是情绪和仓位，是语境，**不能抬升上面任何质量字段**。{NAME} 最近的股价波动里，有多少是真兑现、有多少只是情绪？

## 七、输出
先给一段直接判断，再按下表逐项（每个结论都要能落到证据）：

| 卡住的环节 | 产业链位置 | 排序理由 | 关键证据（强/中/弱·来源） | 主要风险 / 什么情况说明判断错了 |

最后给：
1. **市场可能没看清的地方**（现在被按什么分类、为什么市场慢）。
2. **接下来可能让市场重新定价的事**（事件 + 大致窗口 + 要盯的证据）。
3. **下一步先查的 3 件事**（具体到查哪份文件、哪个指标、哪条客户交叉验证）。

> 可选：若要量化卡点强度，按 Augur 的卡点评分卡（8 因子 0–5：需求拐点/架构耦合/卡点严重度/供应商集中度/扩产难度/证据强度/估值错配/催化剂时点 + 惩罚项），给每项打分并说明依据。

证据不足处一律明说「未验证」，不要编造数字、客户、合同或市值。
