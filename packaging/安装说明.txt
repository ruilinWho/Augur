Augur · 安装说明（macOS · Apple 芯片）
======================================

Augur 是一个完全在你自己电脑上运行的个人投资研究台，不上传任何数据到服务器。
按下面几步即可用起来，大约一分钟。


① 放进「应用程序」
   把 Augur.app 拖到「应用程序」（Applications）文件夹。

② 双击「首次打开.command」
   这个 app 没有购买苹果签名，macOS 第一次会拦它。
   双击随包的「首次打开.command」，它会自动解除拦截 —— 只需做这一次。

   · 如果双击脚本时提示"无法打开，因为来自身份不明的开发者"：
     右键点脚本 → 选「打开」→ 再点「打开」。
   · 如果仍被拦：打开「系统设置 → 隐私与安全性」，
     在底部找到被拦的项目，点「仍要打开」。

③ 打开 Augur
   双击「应用程序」里的 Augur。
   首次启动要等几秒（在准备本地数据），界面出现 🌱 就是正常的。

④ 配置 AI（用于「知 / 研」等智能功能；不配也能看 K 线 / 行情 / 资讯）
   · 若随包附带了 augur-config.json：
       设置 → 配置分享 → 导入 → 选它。
       ⚠ 里面的 key 是作者共享的，额度有限、按量计费由作者承担，请勿外传。
   · 否则用你自己的 key（推荐，长期稳定）：
       设置 → 模型 → 新增连接，填入你的 API key 即可。


你的数据存在哪里？
   ~/资源库/Application Support/Augur/
   （Finder 里按 Shift+Cmd+G 输入 ~/Library/Application Support/Augur 可直达）
   卸载只需把 Augur.app 拖进废纸篓；要清空数据再删上面这个文件夹即可。
